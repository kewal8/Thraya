# Ascendant Serif (EF Studio)

These are the **personal-use** files from https://efstudiotype.com/ and are here for local preview only.
Before the site goes live, buy a commercial / web licence (https://efstudiotype.com/license/) and replace
these files with the licensed ones (same weights: Regular 400, Medium 500, Bold 700).

The `.otf` / `.woff` / `.woff2` files in this folder are git-ignored, so they never reach GitHub.
On a fresh clone, copy the three files here before running `npm run dev` or `npm run build`:
`AscendantSerif-PersonalUse-Regular.otf`, `AscendantSerif-PersonalUse-Medium.otf`, `AscendantSerif-PersonalUse-Bold.otf`.
